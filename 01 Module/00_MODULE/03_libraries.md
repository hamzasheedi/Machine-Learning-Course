# Commonly Used AI/ML Python Libraries (Essential)

This guide lists the essential Python libraries for beginners in data science, machine learning, computer vision, and deep learning, along with installation instructions.

💡 Quick Install Command:

pip install numpy pandas matplotlib seaborn scikit-learn opencv-python pillow tensorflow keras torch torchvision

  

* * *

## 1\. Data Science Libraries

1.  NumPy
    

-   Description: Fundamental package for numerical computing.
    
-   Install: pip install numpy
    

3.  Pandas
    

-   Description: Library for data manipulation and analysis.
    
-   Install: pip install pandas
    

5.  Matplotlib
    

-   Description: Library for creating visualizations.
    
-   Install: pip install matplotlib
    

7.  Seaborn
    

-   Description: Statistical data visualization built on Matplotlib.
    
-   Install: pip install seaborn
    

* * *

## 2\. Machine Learning Library

1.  Scikit-learn
    

-   Description: Tools for predictive data analysis and basic machine learning algorithms.
    
-   Install: pip install scikit-learn
    

* * *

## 3\. Computer Vision Libraries

1.  OpenCV
    

-   Description: Library for computer vision and image processing.
    
-   Install: pip install opencv-python
    

3.  Pillow
    

-   Description: Python Imaging Library for basic image manipulation.
    
-   Install: pip install pillow
    

* * *

## 4\. Deep Learning Libraries

1.  TensorFlow
    

-   Description: Open-source platform for deep learning.
    
-   Install: pip install tensorflow
    

3.  Keras
    

-   Description: High-level neural networks API running on top of TensorFlow.
    
-   Install: pip install keras
    

5.  PyTorch
    

-   Description: Deep learning framework known for flexibility and speed.
    
-   Install: pip install torch torchvision
    

* * *

## Installation Instructions

1.  Open your command line or terminal.
    

Run the pip install command:  
pip install <library\_name>

2.  Replace <library\_name> with the desired library name.
    

Or install all essential libraries at once:  
pip install numpy pandas matplotlib seaborn scikit-learn opencv-python pillow tensorflow keras torch torchvision
