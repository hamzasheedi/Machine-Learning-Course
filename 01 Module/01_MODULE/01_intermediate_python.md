# Data Structures & Algorithms Projects

This section is designed to let learners apply DSA concepts in real Python projects. Each project shows how to implement a data structure or algorithm, why it is useful, and how it connects to real-world tasks, especially in AI/ML workflows.

* * *

## Project 1: Task Manager Using Lists and Dictionaries

Concepts Used:

-   Lists
    
-   Dictionaries
    
-   Loops
    
-   Conditional Statements
    
-   Functions
    

Project Idea:  
Create a command-line Task Manager where users can add, view, update, and delete tasks. Tasks are stored with metadata like task name, priority, and status.

How Concepts Are Applied:

1.  Lists: Store tasks as items in a list.
    
2.  Dictionaries: Each task is a dictionary with keys like name, priority, status.
    
3.  Loops & Conditionals: Iterate through tasks and apply operations based on user input.
    
4.  Functions: Modularize operations: add\_task(), delete\_task(), update\_task(), display\_tasks().
    

Outcome:  
Learners understand dynamic data storage and retrieval, preparing them for dataset handling in ML projects.

## Project 2: Student Database Using Hash Tables

Concepts Used:

-   Hash Tables / Dictionaries
    
-   Functions
    
-   Input & Output
    

Project Idea:  
Build a student database where each student has a unique ID and details like name, age, and grades. Users can search, update, or remove records efficiently.

How Concepts Are Applied:

1.  Hash Tables: Use Python dictionaries with student ID as key for fast lookup.
    
2.  Functions: Create modular operations (add\_student(), remove\_student(), search\_student()).
    
3.  Input/Output: Interact with users to manipulate the database.
    

Outcome:  
Learners experience efficient data retrieval, a critical concept for AI tasks like feature lookup or label mapping.

## Project 3: To-Do App with Stack & Queue Features

Concepts Used:

-   Stack (LIFO)
    
-   Queue (FIFO)
    
-   Lists
    
-   Functions
    

Project Idea:  
Enhance a to-do list where tasks can be:

-   Undone using a stack (last task added is removed first)
    
-   Processed in order using a queue
    

How Concepts Are Applied:

1.  Stack: Implement undo functionality using a stack list.
    
2.  Queue: Implement task processing using append() and pop(0) for FIFO.
    
3.  Functions: Manage operations efficiently.
    

Outcome:  
Learners understand abstract data structures, which are fundamental for AI/ML algorithms like depth-first search, breadth-first search, and priority queues.

## Project 4: Simple Search Engine Using Arrays and Binary Search

Concepts Used:

-   Arrays (Lists)
    
-   Binary Search Algorithm
    
-   Sorting
    
-   Loops
    

Project Idea:  
Create a search system that stores items (e.g., book titles or dataset entries) and allows fast search using binary search.

How Concepts Are Applied:

1.  Arrays/Lists: Store data in a sorted list.
    
2.  Binary Search: Efficiently find items in O(log n) time.
    
3.  Sorting: Ensure the list is sorted before searching.
    
4.  Loops: Navigate through search iterations.
    

Outcome:  
Learners practice efficient data lookup, which is essential for AI tasks like nearest neighbor search.

Project Idea:  
Build a BST to store numerical data and implement recursive traversal methods:

## Project 7: Lambda & Decorator Exercises

Concepts Used:

-   Lambda Functions
    
-   Decorators
    
-   Functions & Lists
    

Project Idea:

-   Use lambda functions to filter or sort a dataset
