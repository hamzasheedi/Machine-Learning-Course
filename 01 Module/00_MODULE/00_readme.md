**Module 0 – Environment Setup & Essential Libraries**
======================================================

Before you begin your journey in AI/ML, it is important to **set up your system properly**. This ensures you can start coding in Python immediately and have the necessary tools installed for AI/ML development.

Welcome to **Module 0**, the starting point of your journey into Artificial Intelligence and Machine Learning. Before diving into complex algorithms and models, it is essential to **lay a strong foundation** by understanding the tools and libraries that make AI/ML possible.

In this module, you will get introduced to the **core Python libraries** widely used in data science, machine learning, computer vision, and deep learning. These libraries are the building blocks for handling data, performing computations, visualizing results, and creating models. Familiarity with them will make your learning experience smoother and more effective as you progress through the course.

By the end of Module 0, you will:

*   Have a clear understanding of the **essential AI/ML libraries**.
    
*   Know the purpose of each library and how it is used in practical AI/ML projects.
    
*   Be prepared to start hands-on experiments and mini-projects in later modules.
    

**This module ensures that you start your AI/ML journey with confidence**, knowing the tools that will support you throughout the course.
